# Fideron

Fideron is an independent software engineering and technology venture focused on building practical tools, platforms, and developer infrastructure.

Our work centres on well-structured software, maintainable architecture, automation, and systems designed to evolve without unnecessary coupling.

## Engineering

Fideron projects follow a consistent development philosophy:

* Changes are developed on dedicated branches.
* All changes enter maintained branches through pull requests.
* Pull requests are reviewed and validated by repository-appropriate CI checks and tests.
* `next` represents the upcoming release line.
* `main` always represents the current released and maintained version.
* Releases follow Semantic Versioning where applicable.
* Published releases use GitHub Releases with generated release notes and changelog history.
* Repository-specific requirements such as integration testing, staging, release candidates, and deployment gates are defined by each project.

Stacked pull requests may be used where they allow larger changes to remain independently reviewable.
